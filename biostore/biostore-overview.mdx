# Alcazar Biostore Overview

## Overview

This document provides an overview of the installation and configuration for **Alcazar Biostore**.
It is intended for system administrators and developers who are setting up the application.

## Installation Guides

Several documents support the installation and configuration of the **Alcazar Biostore** environment.
Use the guides below to ensure a complete and correct deployment.

---

## REST Service Deployment

### Biostore REST Service Guide 

The guide below provides instructions for installing the **Biostore REST service** on your chosen operating system. 
Follow this guide to complete the full deployment of the REST service before performing any configuration tasks.


@deploy-linux-biostore

### Alcazar REST Service Guide

This guide provides step-by-step instructions for deploying and configuring Alcazar REST service applications in Linux environments.

@deploy-linux-rest

## Biostore Containerization

A Biostore-specific containerization guide is provided together with a generic containerization guide that applies to all Alcazar applications.

### Biostore-Specific Containerization Guide

The Biostore-specific guide describes the workflow for packaging the Alcazar Biostore application as a Docker image and deploying it to Kubernetes.

@biostore-containerization


### Alcazar Containerization Guide

The Alcazar Linux Containerization guide explains the standard approach for building Docker images, organizing deployment files, and preparing applications for Kubernetes or standalone container environments.

@linux-containerization

## Configuration Guides

A generic *first-time configuration* guide that applies to all Alcazar services is provided together with the **Biostore-specific** configuration guide.

### First-Time Configuration Guide

A generic configuration guide that applies to all Alcazar services. 
Complete this guide **after installation** and before performing any Biostore-specific configuration.

@configure-first-time

### Biostore Configuration Guide

A Biostore-specific configuration guide that must be followed **after** completing the first-time initialization. 
This guide covers Biostore classes, processing settings, background tasks, accelerators, and workflow integration.

@configure-service-biostore
